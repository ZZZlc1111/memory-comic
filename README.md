# 漫画连续阅读版

双击根目录 index.html，直接从第一章第一个分镜开始。也可将整个文件夹放到静态网站服务器上使用。

- 点击屏幕或右箭头显示下一步，左箭头返回上一步。
- 每章结束后点击，显示留白和下一章标题；再点击，在标题下方加载该章第一格。
- 已读章节留在长页中，可向上滚动回看。后续章节只在进入时加载。
- 右上角“目录”可打开章节列表；“返回阅读”回到刚才的位置。
- 视频保留原生播放、暂停、进度条及全屏控件，播放结束后在下方显示“完”。

## 文件结构

- index.html：连续阅读入口，默认第一章。
- directory.html：可单独打开的目录入口，阅读时不会主动出现。
- script.js、style.css：连续阅读、章节过渡、目录及公共控件。
- chapter1/ 至 chapter10/：保留原有独立章节文件夹。
- 各章 content.js：本章分镜内容、气泡时序及特殊点击步骤，按章加载。
- 各章 index.html：该章独立入口，直接显示第一格并可继续往下阅读后续章节。
- 各章 style.css、images/：原样保留的排版和图片。
- chapter10/ending.mp4：原样保留的视频。

修改单章漫画内容或动画时序，请编辑该章 content.js；修改排版请编辑该章 style.css。
